# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchase records** across multiple product categories. The goal is to uncover insights into customer spending patterns, product preferences, discount usage, customer segmentation, and subscription behavior.

The project follows an end-to-end data analytics workflow using Python for data exploration and cleaning, MySQL for business analysis, and Power BI for interactive dashboard development. The findings are used to identify business opportunities and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze customer purchasing patterns and spending behavior.
- Perform Exploratory Data Analysis (EDA) using Python.
- Clean and preprocess data for reliable analysis.
- Use MySQL queries to answer business questions.
- Identify customer segments, popular products, and discount patterns.
- Build an interactive Power BI dashboard to visualize key metrics.
- Develop actionable business recommendations based on analytical findings.

## 🔄 Project Workflow

### 1. Data Loading and Exploration

- Imported the dataset into Python using Pandas.
- Examined the dataset structure, dimensions, and data types using `df.info()`.
- Generated summary statistics using `df.describe()`.
- Checked missing values and explored the distribution of important variables.

### 2. Exploratory Data Analysis (EDA)

Performed EDA to understand customer behavior and identify patterns in the data.

- Analyzed customer demographics and purchase amounts.
- Explored product categories and customer preferences.
- Examined customer ratings and shopping frequency.
- Investigated discount usage and subscription behavior.
- Identified trends and patterns to guide further SQL analysis.

### 3. Data Cleaning and Feature Engineering

Prepared the dataset for analysis by performing the following tasks:

- Handled missing review ratings by imputing the median rating within each product category.
- Standardized column names using snake_case.
- Created an `age_group` column to categorize customers by age.
- Created a `purchase_frequency_days` feature from purchase-frequency data.
- Checked the relationship between `discount_applied` and `promo_code_used` and removed the redundant column as part of preprocessing.
- Prepared the cleaned dataset for loading into MySQL.

### 4. SQL Analysis Using MySQL

Loaded the cleaned dataset into MySQL and executed SQL queries to answer key business questions.

The analysis covered:

1. **Revenue by Gender:** Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users:** Identified customers who used discounts but spent above the average purchase amount.
3. **Top 5 Products by Rating:** Identified products with the highest average customer ratings.
4. **Shipping Type Comparison:** Compared average purchase amounts between Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers:** Compared customer counts, average spending, and total revenue by subscription status.
6. **Discount-Dependent Products:** Identified products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments based on purchase history.
8. **Top Products by Category:** Ranked the three most purchased products in each category.
9. **Repeat Buyers and Subscriptions:** Examined subscription status among customers with more than five purchases.
10. **Revenue by Age Group:** Calculated revenue contribution across different age groups.

These queries provided insights into customer purchasing behavior, revenue distribution, product performance, and customer retention opportunities.

## 🚀 How to Run the Project

### Prerequisites

Install or configure the following tools:

- Python 3.x
- Jupyter Notebook
- MySQL Server
- MySQL Workbench
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/s1046aishw123-max/Customer_behavior_analysis.git
cd customer_behavior_analysis
```

Replace the URL with your actual GitHub repository URL.

### Step 2: Set Up Python

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter
```

### Step 3: Run the Python Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the project notebook and execute the cells in sequence to load the dataset, perform EDA, clean the data, engineer features, and prepare the cleaned dataset for SQL analysis.

### Step 4: Perform SQL Analysis in MySQL

1. Start MySQL Server and open MySQL Workbench.
2. Create a database for the project.
3. Import the cleaned CSV dataset into a MySQL table.
4. Open the SQL scripts included in the repository.
5. Execute the queries to reproduce the business analysis.
6. Review the query results to identify customer behavior patterns and business insights.

### Step 5: Open the Power BI Dashboard

1. Launch Power BI Desktop.
2. Open the project's `.pbix` file.
3. Update the data source connection if required.
4. Refresh the data.
5. Explore the dashboard using the available filters and visualizations.
